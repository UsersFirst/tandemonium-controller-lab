# @usersfirst/controller-visualizer

3D controller visualizer extracted from Tandemonium. This package will hold the renderer, scene wiring, and per-vendor GLB model bindings that turn live gamepad state from `@usersfirst/controller-core` into an animated on-screen controller — buttons depressing, sticks tilting, triggers pulling — suitable for overlays, debug tools, and tutorials.

GLB controller assets are sourced from [larfingshnew/3d-controller-overlay](https://github.com/larfingshnew/3d-controller-overlay) (MIT). No binary assets ship in this scaffolding pass; they will be added in a follow-up pass along with the upstream `LICENSE` file for proper attribution.
